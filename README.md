# ¡Juntos contra el VPH! — Quiz UPDS

Mini juego educativo en español para la Feria de Promoción de la Salud Comunitaria.

## Funcionalidades
- 8 preguntas de opción múltiple, con explicación de cada respuesta.
- 100 puntos por respuesta correcta, resultado hasta 800 y botón «Jugar otra vez».
- Compatible con celulares y computadores.
- Logotipo UPDS basado en el archivo proporcionado por la organización.
- Sin formularios, nombres, evaluaciones ni conexión a Google Sheets.
- Sitio estático: no almacena ni envía las respuestas de los visitantes.

## Publicación
En el repositorio de GitHub, entra en **Settings → Pages → Build and deployment** y selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
La dirección prevista es:

https://delta-1.github.io/Evaluaci-n-de-la-exposici-n-/

La página solo estará disponible después de activar GitHub Pages. Abre ese enlace en un móvil para comprobar que funciona antes de imprimir o distribuir el QR.

## Mensaje para la feria
**¡Escanea el QR, juega y descubre cuánto sabes sobre el VPH!**

Este material tiene fines educativos y no reemplaza la orientación médica.
